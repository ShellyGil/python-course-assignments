# Periodic Table Quiz Game

A simple Python game to practice element symbols and names from the periodic table.

## How to Play
Run the game and answer the questions by typing the name of the element for each symbol shown.

## Installation
No dependencies are required except Python 3 (standard library only).

## Usage
```
python periodic_table_quiz.py
```

## Testing
To run the tests, use pytest:
```
pytest test_periodic_table_quiz.py
```
